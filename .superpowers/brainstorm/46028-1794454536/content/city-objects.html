Why SpatialQ looks like that

SpatialQ lets people ask questions about map data in a chat. So the object is a stack of floating map sheets (the data layers), a pin dropped on the top sheet (a place), and a speech bubble (the question). In real 3D the sheets can slowly drift apart and back together, and the bubble can cycle through example questions.

How every project gets its own object without modelling each by hand

A kit of about eight object types

Houses, tunnel, bridge, server racks, map stack, robot, factory, satellite dish. Each repo is matched to one type automatically, and colour and size vary per project.
